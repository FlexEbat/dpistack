# Политика безопасности

[English](SECURITY.md) | Русский

dpistack работает от root на хосте, который видит сетевой трафик, поэтому сообщения о повышении привилегий, внедрении команд и утечках секретов принимаются всерьёз.

Сообщайте приватно через GitHub Security Advisories этого репозитория («Report a vulnerability»), не в открытом issue. Цель: первый ответ в течение 7 дней.

Где чувствительные места:

- `dpistack` (копия `install.sh` в `/usr/local/sbin`) единственное, что пользователь панели может запускать через `sudo`. Каждый аргумент проверяется по спискам допустимого до любого действия.
- Секреты лежат в `secrets.conf` (0600) и попадают в `curl` через `-K -` на stdin, никогда в командную строку.
- `scripts/security.sh` и workflow `security` ищут шаблоны, которые обычно приводят к этим проблемам.
