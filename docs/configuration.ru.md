# Справочник параметров

[English](configuration.md) | Русский

Файл `/etc/dpistack/dpistack.conf` (формат `KEY=VALUE`, по строке на ключ). Секреты лежат отдельно, в `/etc/dpistack/secrets.conf` (права 0600), и не показываются нигде: панель и `dpistack settings list` пишут только «задан» или «не задан».

Менять параметры можно тремя способами: экран «Настройки» панели, `dpistack settings set` и `dpistack reconfigure`. Столбец «Изменение» говорит, чем оно обходится: **лёгкое** применяется сразу (перерисовка конфигурации и перезапуск затронутой службы), **тяжёлое** запускает установку или пересборку компонента и идёт отдельной задачей.

Файл создаётся скриптом `scripts/gen-config-doc.sh` из схемы ключей; править его руками не нужно.

## Захват трафика

| Ключ | Значения | По умолчанию | Изменение | Описание |
| --- | --- | --- | --- | --- |
| `SURICATA_MODE` | ids \| ips | `ids` | лёгкое | ids только наблюдает, ips может блокировать. Переключение лучше делать на экране «Компоненты». (расширенный) |
| `IFACES` | строка | `enp2s0` | лёгкое | Интерфейсы, с которых Suricata снимает трафик, через запятую. |
| `BPF_FILTER` | строка | пусто | лёгкое | Фильтр BPF: какой трафик не анализировать или анализировать. (расширенный) |
| `HOME_NET` | строка | `auto` | лёгкое | Ваши сети (CIDR через запятую) или auto: определить по интерфейсам. (расширенный) |
| `IPS_METHOD` | nfq \| afpacket | `nfq` | лёгкое | Как IPS получает пакеты: очередь NFQUEUE или AF_PACKET. (расширенный) |
| `IPS_NFQ_CHAINS` | строка | `INPUT,OUTPUT,FORWARD` | лёгкое | Цепочки iptables, из которых пакеты уходят в очередь. (расширенный) |
| `NTOPNG_IFACES` | строка | пусто | лёгкое | Интерфейсы ntopng. Пусто: те же, что у Suricata. (расширенный) |

| `EVEBOX_RETENTION_DAYS` | целое 0..36500 | `30` | лёгкое | Сколько дней хранить события в EveBox (0: без ограничения). (расширенный) |
