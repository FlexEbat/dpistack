# Справочник параметров

[English](configuration.md) | Русский

Файл `/etc/dpistack/dpistack.conf` (формат `KEY=VALUE`, по строке на ключ). Секреты лежат отдельно, в `/etc/dpistack/secrets.conf` (права 0600), и не показываются нигде: панель и `dpistack settings list` пишут только «задан» или «не задан».

Менять параметры можно тремя способами: экран «Настройки» панели, `dpistack settings set` и `dpistack reconfigure`. Столбец «Изменение» говорит, чем оно обходится: **лёгкое** применяется сразу (перерисовка конфигурации и перезапуск затронутой службы), **тяжёлое** запускает установку или пересборку компонента и идёт отдельной задачей.

Файл создаётся скриптом `scripts/gen-config-doc.sh` из схемы ключей; править его руками не нужно.

## Захват трафика

| Ключ | Значения | По умолчанию | Изменение | Описание |
| --- | --- | --- | --- | --- |
| `SURICATA_MODE` | ids \| ips | `ids` | лёгкое | ids только наблюдает, ips может блокировать. Переключение лучше делать на экране «Компоненты». (расширенный) |
| `IFACES` | строка | `enp2s0` | лёгкое | Интерфейсы, с которых Suricata снимает трафик, через запятую. |
| `BPF_FILTER` | строка | пусто | лёгкое | Фильтр BPF: какой трафик не анализировать или анализировать. Примеры: not port 22, host 10.0.0.5, net 192.168.0.0/16 and not port 53. Пусто: весь трафик. (расширенный) |
| `CAPTURE_THREADS` | строка | `auto` | лёгкое |  Потоков захвата на интерфейс: auto (по числу очередей приёма) или число. Увеличьте, если растёт доля потерь, а CPU свободны. (расширенный) |
| `CAPTURE_TPACKET` | auto \| v2 \| v3 | `auto` | лёгкое |  Версия кольца AF_PACKET: auto (решает Suricata), v2 или v3. v3 быстрее на загруженных каналах; IPS через AF_PACKET требует v2. (расширенный) |
| `CAPTURE_RING_SIZE` | целое 0..1048576 | `0` | лёгкое |  Кадров в кольце захвата каждого потока. 0: значение Suricata. Увеличьте (например, 8192) при потерях пакетов всплесками. (расширенный) |
| `CAPTURE_BLOCK_SIZE` | целое 0..67108864 | `0` | лёгкое |  Размер блока кольца v3 в байтах. 0: значение Suricata; иначе кратное 4096, от 32768. (расширенный) |
| `CAPTURE_CPUS` | строка | пусто | лёгкое |  Процессоры для рабочих потоков детектирования, например 2-5,8. Пусто: решает система. (расширенный) |
| `NIC_OFFLOADS_OFF` | yes \| no | `no` | лёгкое |  Отключать GRO, LRO, GSO и TSO на интерфейсах захвата перед каждым запуском Suricata. Они склеивают пакеты и мешают сборке потоков и детектированию. Нужен нативный запуск. (расширенный) |
| `PCAP_MAX_MB` | целое 1..2048 | `100` | лёгкое |  Самый большой файл захвата в мегабайтах, который принимает dpistack pcap analyze. (расширенный) |
| `FLOW_MEMCAP` | строка | `128mb` | лёгкое |  Память под таблицу потоков, например 512mb или 1gb. Увеличьте, если в статистике растёт flow memcap. (расширенный) |
| `STREAM_MEMCAP` | строка | `64mb` | лёгкое |  Память под отслеживание TCP-потоков, например 256mb. Увеличьте, если в статистике растёт stream memcap. (расширенный) |
| `STREAM_REASSEMBLY_MEMCAP` | строка | `256mb` | лёгкое |  Память под сборку TCP-потоков, например 512mb. Увеличьте, если в статистике растёт reassembly memcap. (расширенный) |
| `HOME_NET` | строка | `auto` | лёгкое | Ваши сети (CIDR через запятую) или auto: определить по интерфейсам. (расширенный) |
| `IPS_METHOD` | nfq \| afpacket | `nfq` | лёгкое | Как IPS получает пакеты: очередь NFQUEUE или AF_PACKET. (расширенный) |
| `IPS_NFQ_CHAINS` | строка | `INPUT,OUTPUT,FORWARD` | лёгкое | Цепочки iptables, из которых пакеты уходят в очередь. (расширенный) |
| `NTOPNG_IFACES` | строка | пусто | лёгкое | Интерфейсы ntopng. Пусто: те же, что у Suricata. (расширенный) |
