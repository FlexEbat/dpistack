## A9 — retention EveBox

**Подтверждено по официальной документации** (не живым тестом, но источник актуален и однозначен: `evebox.yaml` config reference + форум support.suricata.io/EveBox GitHub discussions, версия EveBox 0.18.x).

Встроенная настройка, не отдельный cron/скрипт:

```yaml
database:
  type: sqlite
  retention:
    days: 7      # 0 = отключить; для sqlite это дни
    size: "20 GB"  # опционально, максимальный размер БД
```

Работает только для `type: sqlite` (не для Elasticsearch/PostgreSQL — там retention настраивается иначе). Подтверждается логом `evebox::sqlite::retention: Events purged in last 60s: N` при запущенном сервере. **Вывод: A9 закрыт — механизм встроенный, ключ `EVEBOX_RETENTION_DAYS` из раздела 4 мапится на `database.retention.days`.**
